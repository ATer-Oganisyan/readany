# Правила для агентов

## Общие правила работы

- Отвечай по-русски, если пользователь не попросил другой язык.
- Общайся как с нетехническим специалистом: сначала объясняй продуктовый результат, влияние на пользователя и риски; технические детали добавляй только при необходимости.
- Начинай с результата или следующего действия. Убирай преамбулы, повторы, завершающие любезности и нерелевантные отступления.
- Если от пользователя требуется несколько действий, дай короткую нумерованную последовательность: один пункт — одно действие. В конце укажи один ближайший шаг.
- Об ошибке сообщай предметно: что произошло, где находится причина и как её исправить.
- Для любой работы с русскоязычным текстом используй скилл [$sasha](https://github.com/mishanaer/deslop/blob/main/sasha/SKILL.md).
- Если работа выполняется в Codex и задача касается Expo или React Native, обязательно используй плагин Expo (`expo@openai-curated-remote`) и подходящие скиллы из него. Если плагин недоступен, сначала сообщи об этом пользователю.
- Запрещено устанавливать, запускать и предлагать `ngrok` или другие инструменты для туннелирования трафика.
- Используй [mishanaer/deslop/primitives](https://github.com/mishanaer/deslop/blob/main/primitives/README.md) как дизайн-систему. Сначала ищи существующие компоненты и токены; не создавай локальные аналоги и не подключай другую дизайн-систему без прямого запроса.
- После изменений проверяй результат и указывай, что теперь работает, какие проверки выполнены, что не проверено и какие риски остались.


## Запуск Expo

- Никогда не использовать `ngrok`, Expo Tunnel (`expo start --tunnel`) или другие публичные туннели для запуска проекта.
- Для запуска на физическом телефоне использовать только Expo LAN: телефон и ноутбук должны быть в одной Wi‑Fi-сети, Metro запускается из `packages/app-expo` командой `pnpm start` без флага `--tunnel`.
- Для iOS Simulator использовать прямое локальное подключение к Metro через localhost или LAN, без публичного туннеля.
- После смены Wi‑Fi-сети перезапустить Metro, чтобы Expo выдал актуальный локальный IP и новую ссылку/QR-код.
- Для тестировщиков вне локальной сети использовать устанавливаемую EAS/TestFlight-сборку, а не туннель, и только по явному запросу пользователя.
