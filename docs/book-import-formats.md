# Импорт пользовательских книг

Имя из системного выбора файла используется буквально; URL-декодирование применяется только к URI. Регистр расширения не важен. Неизвестный формат и CBR не должны сохраняться под видом EPUB.

| Исходник | Локальное чтение | Серверная разметка |
| --- | --- | --- |
| EPUB | EPUB | Текст в порядке spine, включая OPF с префиксами XML |
| FB2 | FB2 | FB2; объявленная кодировка, UTF-8 и UTF-16 BOM |
| FBZ / `.fb2.zip` | FB2 из архива | Один FB2 из архива; служебные файлы macOS исключены |
| TXT | Конвертация в EPUB | Исходный TXT; UTF-8, UTF-16 с BOM, распознаваемый русский Windows-1251 |
| PDF | PDF | Текстовый слой через `pdftotext` |
| UMD | Конвертация в EPUB | Полученный EPUB, с SHA-256 именно отправляемых байтов |
| MOBI / AZW / AZW3 | Существующий ридер Foliate | Пока не поддерживается сервером |
| CBZ | Изображения | Текстового слоя нет; OCR не реализован |

Произвольные ZIP, DRM-защищённые книги, PDF без текстового слоя и неизвестные кодировки не становятся автоматически поддерживаемыми. Этот фикс не добавляет OCR и не снимает DRM.

Для FBZ сначала следует обновить сервер: прежняя версия не принимает `format: fbz`. Схема БД не меняется: формат уже хранится как TEXT, миграция и массовое изменение существующих книг не требуются. Откат сервера снова отключит разметку FBZ.

Уже повреждённый результат конвертации TXT автоматически не переписывается. Пользователь может повторно импортировать исходник. Из-за ранее потерянного текста старые позиции чтения и привязки заметок могут не соответствовать исправленной книге.

Регрессионные проверки: `book-import-format.test.ts`, `txt-import-regression.test.ts`, `fb2-encoding.test.ts`, `reader-format-dispatch.test.ts`, `backend-book-sync.test.ts`, а на сервере — `book-source-text.test.mjs`, `book-catalog-api.test.mjs`, `postgres-book-markup-repository.test.mjs`. Мобильный тест отправки подменяет файловую систему и HTTP; тест PDF использует настоящий `pdftotext` (требуется Poppler).
