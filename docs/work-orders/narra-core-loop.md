Ветка: `feat/core-loop-uiux`. Исполнители: автономные агенты (Claude Code / Codex) + ревью Сони.
Форма — work order по методологии hill-climb (репо существует, агенты исполняют слайс).

## Mission

Привести мобильное приложение ReadAny к продуктовому сценарию Narra: интерактивная книга
с живыми героями (fanart-стиль генераций, кликабельные имена, врезки сцен, озвучка по ролям
по правилам) и навигацией из четырёх табов. Ошибки UI/UX и разрывы core loop устраняются
в этой ветке; ничего вне слайса не трогаем.

## Канон стиля генераций (из narra, адаптировано под fanart)

Базовый стиль (в конец каждого промпта изображений, НИКОГДА не сокращается):
«фанарт, стилизованная современная книжная иллюстрация, цифровая живопись с выразительными
мазками, НЕ фотореализм, чистые уверенные формы, мягкий рассеянный свет, сдержанная
благородная палитра, лёгкая текстура бумаги, единая серия работ одного художника,
без текста и надписей»
Портрет: «Погрудный портрет: голова и плечи, строго анфас, ровный светлый фон.
Выражение лица: {expression}. Внешность (соблюдать точно): {паспорт}. Стиль: {СТИЛЬ}.»
Сцена: состав кадра только из перечисленных героев, внешность из паспортов дословно,
одежда из фрагмента важнее паспортной; лимит промпта Kandinsky 950 знаков — при
нехватке места сокращаются паспорта, стиль не режется.

## Правила озвучки (канон)

1. Нарратор и главный герой — голоса ассистентов: Афина, Сбер, Джой.
   Нарратора выбирает пользователь: мужской (Сбер) или женский (Афина/Джой) — в плеере/онбординге.
2. Главному герою — один из оставшихся ассистентских, по полу персонажа.
3. Главный герой: повествование от 1-го лица → рассказчик (нарратор и главгерой — один голос,
   второй ассистентский уходит следующему по значимости); иначе — доля прямой речи + частота
   упоминаний по книге. Ручное переопределение в карточке героя.
4. Остальные — из библиотеки в порядке приоритета, пол строго:
   Фокин, Стерлинг, Галустьян, Стремпаржевская, Цокаева, Безлепкин, Егоров, Чернышова,
   Изволов, Сафронова (приоритет детским/сказкам), Ковалев.
5. Марков и Пират — НЕ в автоназначение, только ручной выбор (пасхалка).
6. Голос закрепляется за героем на всю книгу (кэш). Пул пола исчерпан → повтор голоса
   с изменённой просодией (высота/тембр), уникальность гарантируется только главным.
7. Безымянные эпизодники — голосом нарратора.
Задача агенту: сверить человеческие имена с фактическими кодами реестра
`/v2/speech` (см. NARRA_GATEWAY.md) и зафиксировать маппинг таблицей в
`src/lib/narra/voice-rules.ts`; текущие коды She/Ast/Gal/…/Shi — переиспользовать где совпадают.

## Фазы (приоритет сверху вниз)

- **P1. Стиль генераций** — media.ts (портрет, сцена, фолбэк), generate-book-cover.ts:
  единый fanart-стиль, бюджет 950 знаков (стиль не режется). Acceptance: три промпта
  собираются < 950 знаков со стилем целиком; юнит на бюджет.
- **P2. Правила голосов** — новый `voice-rules.ts` (одна точка правды), выпилить дубли пулов;
  детект 1-го лица (по первым главам: частота «я » вне диалогов), доля прямой речи по героям;
  закрепление в narra-store. Acceptance: юниты на назначение (1-е/3-е лицо, исчерпание пула,
  эпизодники, пасхалки не в авто).
- **P3. Таббар 4 таба** — Библиотека · Читалка (последняя открытая книга, resume на странице;
  пусто → CTA в библиотеку) · Мой путь (открытые персонажи всех книг → чат; бывший
  NarraCharacters + прогрессы) · Профиль (настройки + поиск по книгам; «Заметки» переезжают
  в стек Профиля). Acceptance: холодный старт → Читалка открывает последнюю позицию ≤ 2 c
  после кеша; все старые экраны достижимы.
- **P4. Библиотека** — секция «Читаю сейчас» сверху с прогресс-баром и %, стиль карточек
  по deslop-primitives (эффект «скрученного края» — MVP: page-curl тень/уголок).
- **P5. Кликабельные имена** — инъекция разметки имён героев в foliate WebView (стемминг
  падежей, общие фамилии двух героев не матчатся), тап → карточка героя (портрет, черты,
  паспорт) → чат. Acceptance: «Гермиону»/«Гермионы» кликабельны, «Малфой» при двух
  Малфоях — нет.
- **P6. Врезки сцен** — предложение сцены каждые X страниц (X в настройках, деф. 8) баннером
  в конце экрана + кнопка регенерации на готовой сцене. Кэш по позиции.
- **P7. Озвучка из читалки** — вход с нижней панели читалки: /v2/speech по ролям с правилами P2,
  скорость, подсветка текущего фрагмента (foliate overlayer), пауза/резюме. Системный TTS
  остаётся офлайн-фолбэком.
- **P8. Единая панель Apple Books** — свести TOC/закладки/поиск/темы в один вход (образец
  ReaderPanels из narra: AA-панель тем + ☰-панель навигации).

## Hard rules

- Не менять: gateway-контракт (NARRA_GATEWAY.md), схемы БД без миграций, foliate-js вендор
  (кроме documented hooks), дизайн-систему deslop-primitives (использовать, не форкать).
- Никаких ngrok/туннелей; Expo LAN. Секреты не коммитить.
- Каждый кусок — отдельный коммит с русским сообщением по AGENTS.md; после изменений
  прогонять typecheck/lint/тесты пакета.
- Ledger: docs/work-orders/narra-core-loop-ledger.md — фаза, гипотеза/изменение, коммит,
  проверки, статус.

## Definition of Done

Все фазы P1–P8 закрыты коммитами с зелёными проверками, ledger заполнен, по каждой фазе —
скриншот/запись экрана в PR, известные ограничения перечислены честно.
