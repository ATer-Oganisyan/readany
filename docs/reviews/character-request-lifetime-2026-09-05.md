# Принадлежность незавершённых запросов персонажа

## Результат

Четыре AI-пути экрана — ответ, приветствие, placeholder и память — используют
общую область запроса, подписанную на состояние книги. Смена edition/SHA,
удаление книги из Narra store или исчезновение персонажа навсегда отменяют
запрос. Возврат A→B→A не оживляет его. Перед записью выполняется повторная
проверка текущего состояния; сигнал отмены проходит в gateway consumer.
Ожидаемая отмена не показывается как ошибка сервиса.

## Доказательства

- Mounted screen + настоящий completeNarraChat с тестовым HTTP-адаптером:
  три RED до исправления (rebind, удаление, A→B→A) сохраняли старый ответ.
- После исправления 15 тестов экрана PASS: эти переходы, stale greeting,
  placeholder, memory, прежние таймауты и повторная отправка.
- Helper: 8 тестов на настоящий Zustand store, включая снятие подписки,
  неизменную идентичность и регистр SHA.
- Полный mobile: 176 suites / 1630 PASS; TypeScript и diff-check PASS.

## Дополнение: жизненный цикл экрана

Сессия экрана теперь привязана к book/character/edition/SHA. При смене ключа
она создаётся заново, поэтому приветствие и placeholder не наследуют старые
ref-флаги. Все её запросы отменяются при размонтировании. До отправки
проверяется не только текущий store, но и принадлежность контекста render:
старый обработчик не может отправить прежний prompt под новой привязкой.

Добавлены проверки старого handler, pending send после unmount и нового
приветствия/placeholder после переключения. В тестах unmount сначала
коммитится отдельным act, затем вызывается обработчик или приходит ответ.
Независимое ревью выявило StrictMode replay: два дополнительных mounted RED
подтвердили пропуск приветствия/placeholder. Setup теперь сбрасывает флаги,
а отменённый прежний запрос не меняет флаг/индикатор новой генерации.

Последний полный прогон: 176 suites / 1637 PASS; TypeScript и diff-check PASS.

## Оставшиеся границы

Нет новой native/live-provider приёмки. Область следит за Narra store,
не за отдельной стадией удаления только из Library store. Потеря фокуса без
размонтирования не равна закрытию сессии и сама по себе запрос не отменяет.
Миграция legacy-идентичности и ограничения размера архивов отдельные.
Подписочный транспорт генерации в этом этапе не менялся.
