# Несколько чанков через тестовый шлюз: подготовительная приёмка

Результат: отдельный фиксированный план `siblings` прошёл с mock-моделью через
настоящие workers, отдельную PostgreSQL и локальный HTTP generation service.
Живые вызовы в этом этапе не выполнялись; `runPipelineCanary` по-прежнему
отклоняет `fixtureId: 'siblings', stagedLive: true`.

## Контроль запросов

- Три разных стандартных чанка собственного текста; проверяются точный контекст,
  core range, chunk ID и run ID. Порядок сканирования может отличаться.
- Затем две полные тройки synthesis → recall → audit для Анны и Бориса.
  Идентичность внутри тройки неизменна; повтор героя или чанка запрещён.
- Максимум девять вызовов; каждый требует отдельного разрешения точных байтов
  по SHA256, nonce и индексу. Контроллер не создаёт разрешения сам.
- Предел 32 KiB, сроки ожидания, одна попытка, остановка при ошибке/квоте,
  отсутствие fallback сохранены. Старый четырёхшаговый `window` не заменён.
- Автоматический reviewer существует только внутри mock-теста и проверяет
  `manifest.mode === 'mock'` перед созданием разрешения. Это не live approval.

Официальный `codex exec` поддерживает скриптовый запуск и сохранённую CLI
авторизацию; токены здесь не читаются и не копируются. Это локальный QA-инструмент,
не доказательство готовности подписки как production inference API.
[Официальная документация](https://learn.chatgpt.com/docs/non-interactive-mode).

## Что усилили в оценке персонажей

Старый gold допускал отсутствующую профессию Анны, пустые примеры речи и даже
описание связи как супружества при верных двух ключах персонажей. Root воспроизвёл
эти три ложных успеха на версии `897defd` и проверил отказ нового gate.

Теперь проверяются профессия «хранитель архива», точная собственная реплика
каждого героя и смысл «сестра и брат». Evidence ID должен указывать на существующую
цитату правильного типа и владельца. Борису профессия не выдумывается.
Прежние проверки 11 фактов, traits, поздней черты и отсутствия ранней утечки сохранены.

## До живого прогона

Нужен отдельный semantic live-gate, не ослабление строгого mock-gate. Scanner
просит дополнительные character_mention и допускает другие подтверждённые факты;
поэтому ровно 11 observations — не корректный критерий живого качества.
Заранее определить допустимые морфологические варианты трёх trait-концептов,
проверять полноту обязательных утверждений, точные цитаты/владельцев и
подтверждённость дополнительных фактов. Проверить роль, родство, описание и
собственные реплики; устойчивый стиль речи по одной реплике не выдумывать.

После независимого review — отдельная серия максимум девяти живых запросов
с просмотром каждого body и предыдущего ответа. Неожиданная reconciliation,
повтор или превышение лимита останавливает серию. Не разрешать их автоматически.

Био/стиль диалога, мобильный AI-loop, изображения, звук, cost ledger/S3 и
тысячи пользователей этим этапом не приняты. Canonical timeline не делает
публичный финальный профиль spoiler-safe.
