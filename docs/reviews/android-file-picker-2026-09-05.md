# Android: импорт из файлов и честный результат

## Пройденный клиентский путь

На Android LOCAL `95a8e05` выполнен импорт через настоящий системный picker,
а не URL или прямой вызов store. Использованы собственные fixtures:

| Файл | Проверенный результат |
| --- | --- |
| `04-letter-cp1251.fb2` | Added 1, русское название и текст Windows-1251 читаются |
| `08-archive.fbz` | Added 1, архив открывается, кириллица читается |
| `12-river-comic.cbz` | Added 1, raster-страница отображается; page 1 → 2 → Library → page 2 |
| Повтор `04-letter-cp1251.fb2` | Added 0 / updated 1, без новой карточки |
| `21-broken.fb2` | Added 0 / failed 1, повреждённый файл не создал карточку |

Файлы скопированы только в собственную папку `Download/NarraLocalQA`, без
очистки чужих каталогов. Downloads provider сначала не показывал adb-pushed
файлы; штатный путь storage root → Download → NarraLocalQA показал все четыре.
Это ограничение подготовки QA/индексации, не доказанный дефект фильтра Narra.

После прогона persisted library содержит шесть книг. Root независимо сравнил
ID, полные CFI и progress трёх защищённых own01/own27/own02 с предыдущим
snapshot: точное равенство. Никакие книги в этом прогоне не удалялись.
CBZ сохраняет `epubcfi(/6/4)`, progress `0.4993867156933091` и открывает raster
страницы 2. Текст на изображениях взят из собственного PDF-fixture; это
CBZ, а не повторная проверка PDF-движка.

## Найденная ошибка обратной связи

После успешного файлового импорта поддерживаемого формата приложение обещало
скоро добавить обложку и персонажей. Условие проверяло только формат и число
добавленных книг; подтверждения провайдера, manifest или задания не было.
На проверяемом LOCAL AI-провайдеры не готовы. Таким образом, успешное сохранение
ошибочно выдавалось за обещание будущей AI-обработки.

Коммит `2ac0d97` сообщает только подтверждённое: «Импорт завершён. Можно читать».
Необоснованная AI-иконка удалена. Счётчики, Open, обновление существующей книги,
частичные ошибки, отмена и lifecycle сохранены; дополнительных запросов,
задерживающих чтение, не добавлено. Одинаковое правило применяется к file/URL.

Три mounted RED → GREEN; 67 профильных проверок и 11 i18n PASS.
RU/EN проверены, English source revision обновлена. Root: mobile1733/core697
PASS, TypeScript обоих пакетов PASS. Точный финальный QA-снимок `2ac0d97`
также прошёл mobile1733 и мобильный TypeScript.
