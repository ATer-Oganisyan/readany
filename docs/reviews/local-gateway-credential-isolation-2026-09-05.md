# Изоляция локальной авторизации перед живым QA

## Воспроизведённая проблема

`narra-gateway-fetch` использовал одни SecureStore-ключи для любого URL.
При сохранённом действующем TEST-токене первый запрос к localhost отправлял
этот токен вместо регистрации отдельной установки. Восстановление после
отклонения идентичности могло удалить прежние общие ключи.

Поведенческий регресс воспроизвёл проблему через настоящий
`narraGatewayRequest`, подменяя только HTTP и SecureStore:
**27 PASS / 1 FAIL** до исправления. Первый запрос ошибочно шёл в catalog,
а не в local installation registration.

## Исправление

Для localhost, 127.0.0.1, IPv6 loopback и Android emulator host 10.0.2.2
ключи installation ID, secret, token и expiration изолированы по endpoint
(origin и path, включая порт). Кодирование обратимое и без коллизий между
ASCII URL; содержит только допустимые символы ключей SecureStore.
Удалённые legacy-ключи не мигрируются и не удаляются.

URL является build-time конфигурацией: для переключения нужен reload Metro.
Это изменение не заявляет поддержку смены endpoint посреди активных запросов.

## Проверки

`pnpm exec vitest run src/lib/ai/narra-gateway-fetch.test.ts`:
**28 PASS** после исправления. Новый сценарий проверяет:

1. Remote credentials не попадают в локальную регистрацию/запрос.
2. Remote storage остаётся неизменным.
3. После перезагрузки модуля local использует собственный сохранённый токен.
4. Другой local port регистрирует отдельную установку.
5. Возврат к TEST использует прежний remote token без новой регистрации.

Biome check двух изменённых файлов — PASS.
Полный штатный `pnpm test` приложения: **165 suites / 1476 tests PASS**,
5.05 секунды на этой машине. Это время тестов, не метрика скорости приложения.

## Ограничения

Это защита авторизации, а не доказательство полной изоляции книжных данных.
Перед переключением устройства ещё нужно проверить привязанные к backend
edition IDs и кэши анализа. Общие ключи между двумя удалёнными окружениями
сохранены для совместимости; их отдельная миграция в эту правку не входит.
Живой local-generation loop этим тестом не принят.
