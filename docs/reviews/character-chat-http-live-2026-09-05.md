# Персонаж: фактический клиентский запрос через подписочный HTTP-шлюз

## Что подтверждено

Из mounted-экрана получен реальный запрос Анны; он прошёл серверные contract,
policy и provider serialization. Отдельный HTTP canary использует фиксированный
upstream SHA `7d6447e6b37eebc4e482a2381e921be09aa9fc05b9d378dfc65dfa1875c76259`,
не разрешает произвольные запросы, повтор или fallback. Default — model-free
dry-run, `--mock` и `--live` включаются явно. Старый canary не менялся.

Root независимо проверил 5 HTTP-тестов: реальный изолированный gateway с mock
CLI, registration/authentication, один вызов, неверные pins/режимы, пустой ответ
и очистка собственных bridge-каталогов после закрытия child. Совместный прогон
двух capture-наборов и HTTP-набора: 9/9 PASS. Агент независимо проверил HTTP.

Один live-вызов gpt-5.6-luna: HTTP6349мс, runner6532мс, attempts1,
request_id `7fae20aa-9cd2-46e5-86bb-2dcf4bd74c95`. Исходный результат сохранён в
`evidence/character-chat-live-2026-09-05.json`. После результата runner завершился
exit0, включая finally с ожиданием закрытия собственных процессов.

## Качество ответа

Ответ по-русски от первого лица, короткий; течь, Лев и доска соответствуют
контексту. «У берега» присутствует во входном контексте. Однако слово «быстро»
добавляет неподтверждённую характеристику действия: соответствующего факта
во входе нет. Качество не принимается как 10/10. Это конкретное наблюдение
для дальнейшей проверки groundedness, не основание подгонять ответ под одну фразу.

## Возврат ответа в клиент

Добавлен третий mounted-сценарий: записанный настоящий HTTP completion проходит
реальный mobile parser и сохраняется в нужные book/character. Хеш сформированного
в этом сценарии запроса обязан совпадать с исходным mobile SHA записи.
Это offline replay, не живой тап на устройстве и не проверка реальной SQLite.
Агент независимо просмотрел diff/запись и повторил все3 сценария PASS:
completion не подменён, исключён только request_id, SHA и запись ответа совпадают.

Root: канонический `pnpm test` —178 файлов/1666 PASS, TypeScript exit0.
Прогон выполнен в основной локальной установке зависимостей (RN0.86.2),
не в отдельной RN0.86.3 native-сборке. Новая проверка workflow: actionlint PASS.
Предварительный широкий `vitest run` без штатных путей завершился exit1:
он ошибочно подхватил node:test-скрипт bundled-audio как Vitest-suite.
Это не успешный полный прогон и не новое падение приложения; после него
использована каноническая команда из package.json.

## Незакрытые границы

- Нативный экран с живым провайдером пока не принят; постоянный LOCAL gateway
  этим запуском не перенастраивался.
- Один образец не задаёт p95/SLA, качество длинных диалогов или защиту от спойлеров.
- gateway не возвращает finish_reason; отсутствие обрезки не доказано.
- Генерация профилей из полных книг, Narra tools, сцены, картинки и синтез речи
  требуют собственных сквозных проверок. Подписочный CLI не объявляется
  универсальным production API для тысяч пользователей.

Использованы Expo native-data-fetching и OpenAI Docs. Официальный CLI допускает
неинтерактивный запуск и повторное использование сохранённой авторизации;
файлы авторизации не читались и не копировались:
https://learn.chatgpt.com/docs/non-interactive-mode.
