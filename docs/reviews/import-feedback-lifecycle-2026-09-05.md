# Импорт: уход с экрана и повторная Android-проверка

## Исправление обратной связи

URL-импорт сбрасывает download controller перед атомарным сохранением. Если
пользователь уходил с экрана во время сохранения, бесконечное уведомление
«Добавление книги…» оставалось: завершение уже не показывало результат, а
unmount отменял только скачивание. Два mounted-теста воспроизвели RED:
успешное и ошибочное завершение отложенного сохранения.

Теперь экран отслеживает только своё активное loading-уведомление и закрывает
его сразу при unmount. Сохранение не отменяется, временный файл остаётся до
его завершения. Поздняя ошибка не показывает сообщение на другом экране;
поздний успех не вызывает навигацию или callback экрана. Уже показанное
конечное уведомление при последующем unmount не удаляется.

Четыре новых поведенческих теста покрывают оба исхода незавершённого сохранения
и сохранение конечных уведомлений. Использован Expo native-data-fetching для
разделения отмены загрузки, времени жизни экрана и атомарного сохранения.
Нативная проверка этого нового изменения ещё не проведена.

Root и независимый агент: import-actions58/58 PASS; TypeScript exit0.
Независимое ревью не выявило блокеров в этом исправлении.

Следующий проход воспроизвёл ещё4 RED: поздние ошибки picker, локального
сохранения и native URL prompt показывались после ухода, а поздний успешный
picker запускал новый импорт. Добавлены проверки mounted перед началом импорта
и показом ошибок. Уже начатое сохранение не отменяется. Root и независимый
review:62/62 PASS, TypeScript exit0. Нативный прогон этих guards ещё не выполнен.
