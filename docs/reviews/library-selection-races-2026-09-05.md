# Выбор книг во время удаления и фильтрации

## Клиентский результат

Коммит `50c1db2` сохраняет новые действия пользователя, пока подтверждённое
удаление завершается в фоне. Завершённая операция больше не заменяет весь
текущий выбор списком своих ошибок.

- Удалить A → выйти из выбора → выбрать B: поздний результат A не сбрасывает B.
- Удалить A → добавить B, не выходя: B остаётся; при успехе снимается только A.
- Удалить A → снять A → ошибка удаления: A не выбирается заново против действия
  пользователя. Ошибка по-прежнему отражается в итоговом уведомлении.
- Смена фильтра с A на B при равных количествах больше не означает «всё выбрано».
  Переключатель действует только на видимые ID, сохраняя скрытые отметки.

Подтверждённый список удаления фиксируется при запросе. Новые выбранные книги
не добавляются в него. Удаление после ухода с экрана продолжается, но поздний
UI после unmount не публикуется, как и раньше.

## Реализация и доказательства

Состояние режима и набора ID обновляется атомарно. Идентификатор сессии выбора
защищает новый вход после Cancel. Внутри сессии production-helper вычитает из
**текущего** набора только успешные ID конкретной операции, не подмешивая
снятые пользователем неудачные ID обратно.

Mounted-тесты используют настоящий hook удаления и этот production-helper,
отложенные Promise успешного/ошибочного удаления, состояние React, уведомления
и повтор. Два новых session-сценария: RED → GREEN; четыре same-session случая:
три RED и один исходный PASS → все GREEN. Две дополнительные mounted-проверки
совмещают смену видимого набора/Select all с незавершённым удалением и проверяют,
что новая B не удаляется.

Для видимого выбора старые count/reset выражения извлечены в функцию;
5 из 6 проверок падали до исправления сравнения и сохранения скрытых ID.
Это host-регрессии, не воспроизведение фильтрации на устройстве.

Итого: 20 mounted batch-тестов + 6 тестов видимого выбора PASS.
Полный мобильный прогон: 181 файл / 1733 теста PASS, TypeScript PASS.
Подключение проверено по diff `LibraryScreen`; полный экран не смонтирован
в этих тестах, а новые гонки на эмуляторе пока не инъецировались.
