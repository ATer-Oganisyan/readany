# Импорт: матрица нативной приёмки, 2026-09-05

Цель: любая поддерживаемая книга добавляется целиком и сразу читается; ошибка, повторное добавление и AI не портят библиотеку и сохранённое место. Успех импорта не равен успеху открытия: обязательны оба шага.

## Реальные входы мобильного клиента

| Вход | Действия пользователя / реализация | Статус нативной проверки |
| --- | --- | --- |
| Файл, непустая библиотека | Библиотека → меню добавления в шапке → «Выбрать файл» → системный picker; `use-book-import-actions.ts` | iOS и Android: picker, импорт и чтение собственных книг прошли; это не все document providers |
| Файл, пустая библиотека | Центральное меню добавления → «Выбрать файл»; тот же hook | Android: настоящий picker прошёл; отдельный iOS empty-library вход не подтверждён |
| Несколько файлов | Picker с `multiple: true`; смешанная очередь хороших/повреждённых/повторных книг | На обеих платформах сохранность данных и счётчики Added/updated/failed прошли. Android Details дополнительно принят по строгому OCR bounds→physical tap с существующим RN Pressable; экспериментальный Sonner patch не устанавливался |
| Прямая ссылка HTTP(S) | Меню добавления → «Найти по ссылке» → native prompt → загрузка файла → тот же импорт | Обе платформы localhost: success/redirect/changed-edition/truncated/404/stall-Cancel проверены. iOS redirect сохранил прежнюю запись/CFI; другая редакция добавлена отдельно, SHA256 обоих файлов совпали с соответствующими источниками. | Фикбук | То же поле URL, распознаётся `/readfic/<id>`; страницы → собственный EPUB | Не проверено; живой сайт не подменять локальным URL |
| Каталог / популярные | Карточка каталога в библиотеке или категории → Reader; backend source download → импорт → чтение | TEST API HTTP 502: failure/retry UI наблюдался, live success path не принят |
| Встроенный каталог | Reader route с `catalogBookId` → bundled asset → импорт; отдельная ветка от backend catalog | Не проверено; достижимость текущим UI уточняется |
| Cloud/WebDAV/S3 download | Удалённая синхронизированная книга → скачать → локальная книга; `screens/library/useBookDownload.ts` | Полный account sync не проверен; нужны реальные настроенные источники. На iOS/Android отдельно прошёл настоящий Expo transport localhost stall/timeout/retry/precancel; это не WebDAV/S3 E2E |
| Восстановление потерянного файла | Открыть запись с отсутствующим источником → выбрать файл → проверка соответствия → подтверждение → reimport с сохранением заметок/места | Android Library CBZ: id/hash/CFI `/6/4`, стр. 2/4 сохранены. iOS после [исправления picker](ios-import-picker-2026-09-05.md): тот же ID/hash/CFI `/6/6`, стр. 3/4, Library 20→20. Отдельные Notes/Profile repair не подтверждены. Перемещались только собственные audit-файлы, с проверенными резервными копиями |
| WebDAV import browser | `WebDavImportBrowserScreen` зарегистрирован в navigator, содержит выбор/папку и `importBooks`; активный вход из Library не найден | Не считать доступным UI, пока не доказан путь |
| Share-in / «Открыть в NARRA» | Обработчик входящего native файла не найден; expo-sharing используется для экспорта | Не реализованный канал, не заявлять как проверенный |

### Дополнение: настоящие Kindle-контейнеры

Позднее набор расширен файлами `23-river.mobi`, `24-river.azw3`, `25-river.azw`
из оригинального `01-river.epub`. Скрипт
`scripts/generate-kindle-audit-fixtures.mjs /path/to/ebook-convert` принимает
локальный [Calibre](https://calibre-ebook.com/download_osx), сам ничего не
скачивает/не устанавливает и регистрирует размеры/SHA в manifest. В этой
кампании использован официальный Calibre 9.14.0 из отдельной временной папки;
SHA256 DMG сверён с официальным release asset:
`a2f825138645ea29d9f77a78c177216c0db855fa0c7b993a16ace230c04fe3d4`.

`file` подтвердил PalmDB/Mobipocket, UTF-8, MOBI6 для 23 и KF8/MOBI8 для 24.
25 проверяет DRM-free MOBI6 под расширением AZW, **не** DRM/KFX и не файл,
загруженный из Amazon. Названия отличаются, текст/главы принадлежат audit-набору.
Создание файлов само по себе не считается нативной приёмкой. Позднее все три
прошли настоящее открытие, читаемую кириллицу, по 10 физических нажатий и возврат
в библиотеку на iOS и Android; свидетельства в platform reports. DRM/KFX не принят.

## Ссылки и ошибки сети

Локальный сервер: `node packages/app-expo/scripts/serve-import-audit-fixtures.mjs`; слушает **только 127.0.0.1:8099**, не публикуется наружу. Android: `adb reverse tcp:8099 tcp:8099`. iOS Simulator использует localhost напрямую.

- `/01-river.epub`, `/03-island.fb2`, `/05-lantern-utf8.txt`, `/11-river-library.pdf`: обычные URL.
- `/02-%D0%BC%D0%B0%D1%81%D1%82%D0%B5%D1%80%D1%81%D0%BA%D0%B0%D1%8F%20100%25.EPUB`: закодированное имя.
- `/redirect.epub`: 302 к валидному EPUB; `/missing.epub`: 404; `/error.epub`: 503.
- `/18-not-a-book.epub`: HTTP 200 с HTML вместо книги; `/stall.epub`: headers и первые байты, затем зависшее тело (закрывается сервером через 90 секунд).
- Повторное нажатие добавления; отмена native prompt/picker; выход со страницы во время скачивания; offline/возврат сети.

## Обязательный цикл для каждого положительного формата

1. Добавить через системный UI, записать результат и время до доступности чтения.
2. Открыть, проверить начало, оглавление/страницы, перелистать не менее 10 раз, включая быстрые серии.
3. Открыть персонажей/сцену; вернуться к тому же тексту. При неподдерживаемом AI чтение остаётся доступным.
4. Выйти в библиотеку, открыть снова; затем force-stop и открыть снова. Сопоставить текст и место, а не только процент.
5. Повторно импортировать тот же файл/переименованную копию. Проверить отсутствие дубля и сброса места.
6. Импортировать повреждённый файл, затем нормальный. Старые книги продолжают открываться, очередь освобождена.

Нативные результаты ведутся отдельно с платформой, bundle/APK, SHA/worktree,
шагами и снимками: [iOS](ios-native-qa-2026-09-05.md),
[Android](android-native-qa-2026-09-05.md). Таблица выше обновлена по этим фактам;
созданный, но не запущенный flow остаётся «не проверено». Обязательный полный
цикл не считается автоматически пройденным для каждого формата: 10 нажатий
не заменяют force-stop/AI/repair всех вариантов.

## Исправления и проверки перед передачей нативному QA

- Воспроизведены фактические phantom-книги: HTML под расширением EPUB, незакрытый FB2, обрезанный PDF. До исправления `importBooks` сохранял и публиковал все три. Теперь отдельная проверка содержимого стоит до копирования/DB/AI как в обычном импорте, так и восстановлении файла; ошибки не создают запись.
- Воспроизведены и исправлены зависание обычного URL download (135 секунд, транспорт получает abort), зависшее тело HTML/обложки Фикбука после успешных headers, двойное открытие URL prompt/загрузки, ложная ошибка при удалении временного файла после успешного импорта.
- Согласованы `.fb2.zip` в local/URL/WebDAV и ZIP MIME в picker; CBR отклоняется как неподдерживаемый RAR, не маскируется под CBZ.
- Исторический целевой mobile прогон этого этапа: 121 тест, 12 файлов, ошибок нет; TypeScript без ошибок. Core WebDAV: 8/8. Это не текущий общий счётчик и не замена UI.
- Реальный валидатор принял все 17 встроенных EPUB и 10 положительных EPUB/FB2/FBZ/PDF/CBZ fixture-входов, отверг 4 повреждённых/пустых XML/EPUB fixture. UMD проверен настоящим parser: 3 главы и правильное название.
- Android debug arm64 собран локально: `BUILD SUCCESSFUL in 9m 23s`, 824 задачи; APK `packages/app-expo/android/app/build/outputs/apk/debug/app-debug.apk` (~110 МБ). Установка/запуск выполнены root; сами Android UI loops переданы отдельному агенту.
- Root iOS реально добавил первые шесть книг и обнаружил испорченное CP1251 название у `04-letter-cp1251.fb2`. Metadata/body codec исправлены; нативные повторы на обеих платформах подтвердили название и читаемый текст. Последующее iOS восстановление после немедленного завершения процесса остаётся отдельной проверкой, не следует из codec PASS.

Ограничение проверки контейнера: PDF проверяется по сигнатуре/завершённому trailer,
CBZ по наличию страниц в ZIP; это не полная отрисовка каждого возможного файла.
FB2 проверяется целиком (включая XML-структуру), поэтому время/память очень крупных
FB2 нужно измерить отдельно на устройстве. Визуальные дефекты PDF и CBZ исправлены
и проверены нативно на собственных fixtures; широкая матрица PDF-шрифтов,
fixed-layout EPUB, DRM/KFX и повреждённых Kindle-контейнеров не покрыта.
