# Приёмка сохранённой разметки и повтор без генерации

Исправлены ложные отказы evaluator на неизменённой публикации живого прогона
09-06. Связь идентифицируется по двум явным различным участникам, а не по её
подписи. Legacy-подписи разрешены только при отсутствующем поле участников;
явные пустые/неверные поля не обходят проверку. Подпись не позволяет спрятать
дубликат той же пары и цитаты. Смысл опубликованного родства, источники и
ключи персонажей проверяются как раньше.

Собственная реплика разрешена в четырёх точных формах: полная атрибуция,
внутренний текст, текст в исходных кавычках, те же кавычки с исходной точкой.
Каждая форма должна быть дословной частью её источника. Произвольные подстроки,
изменённые слова, отрицания, вопросы, многоточия и чужая реплика не принимаются.

34 evaluator tests PASS, включая unchanged live artifact. Отрицательные проверки
источников, владельцев и ранних future citations сохранены. Независимый review
добавил explicit undefined/string/array-like участников — все отклоняются.
Весь related model-free набор60 PASS на Node24.20.0.
