# Scan: отмена ожидания хранилища и полный PG/S3 regression

Потеря lease теперь отменяет не только генератор, но и `getBytesRange`.
Signal проходит в AWS SDK. Если заголовки уже получены, обработчик отмены
закрывает Node-stream тела; ошибка нормализуется к причине LEASE_LOST.
До исправления три HTTP-регрессии падали: pre-aborted запрос отправлялся,
ожидание заголовков и частичного тела не завершалось после отмены.

На Node 24.20.0 — **42 targeted PASS**. Настоящий AWS SDK обращается только
к собственному loopback HTTP. Проверены закрытие соединения, отсутствие
повторов/лишнего запроса, очистка listeners, byte cap и целостность диапазона.
Worker-тест завершается по signal без ручного освобождения storage-заглушки;
генерация/commit/fail не вызываются. Основной агент независимо прочитал diff
и повторил тесты. Expo Networking использован для сквозной отмены.

Ограничение: активное закрытие тела гарантируется для Node-stream AWS SDK.
Произвольный пользовательский iterator/transform без destroy не получает
такой гарантии. Нового общего timeout для всех storage-запросов не добавлено.
