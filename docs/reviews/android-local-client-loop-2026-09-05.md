# Изолированный Android LOCAL: клиентский прогон

## Окружение

- Новый AVD `Narra_LOCAL_QA_20260905`, Android API36 arm64, serial `emulator-5556`. Исходный TEST `emulator-5554` / `Readest_API_36_arm64` не перенастраивался.
- Попытка второго read-only экземпляра TEST-AVD завершилась отказом эмулятора: все одновременно работающие экземпляры одного AVD должны быть read-only. Повторно не запускали и исходный TEST не останавливали.
- Создан отдельный AVD через установленный avdmanager с Java17. Запуск: `-port 5556 -no-snapshot -no-window -no-audio -no-boot-anim -memory 2560`.
- В чистое QA-устройство установлен только существующий APK, извлечённый из установленного TEST-приложения; пользовательские данные/учётные записи не переносились. APK SHA256 `2f7711135ebe5f1f03d377ea719f867b082fe0ff5c972a33a0028d08af9db8cf`, versionName1.3.5/versionCode1. Это не доказательство соответствия native-кода текущему HEAD; нативной пересборки не было.
- JS: текущий Metro8082, HEAD `a50b47e`. Reverse только8082 и18787. Старт через `readany-dev://expo-development-client/?url=http%3A%2F%2F127.0.0.1%3A8082`, COLD, exit0.
- Read-only Hermes подтвердил `development`, `http://127.0.0.1:18787`, installation auth, пустую библиотеку. Root лично просмотрел `/private/tmp/narra-local-5556-launch.png`: Library и стандартный onboarding dev-menu. iOS XCTest/AX не запускался.

## Приёмка сценария

Собственная книга: `27-fresh-boundary.fbz`, 2199 bytes, локальная ссылка `http://10.0.2.2:8089/27-fresh-boundary.fbz`. Путь: My books → Add book → Add from link → Add → Open → Reader → Library → Reader. Требуется проверить сохранение точного CFI и прогресса, а не только факт открытия.

Первый setup-прогон остановился после Continue, поскольку dev-menu оставался открытым. Две дальнейшие попытки верхнего Add открыли dev-menu вместо импорта. Hierarchy выявила перекрытие: Expo Tools `[937,213][1005,281]` и Add book `[955,179][1018,242]`. Это препятствие отладочного UI, не подтверждённый дефект импортера. Для входа использована отдельная штатная кнопка добавления в пустой библиотеке; прямого вызова React-handler не было.

Импорт по ссылке завершился успешно: `/private/tmp/narra-local-5556-imported.png` лично проверен root. Карточка «Аудит27 — Граница глав» видна; toast показывает added1/updated0/skipped0/failed0 и кнопку Open. Нажатие Open не принято: toast истёк; книга открыта карточкой.

Ограниченный цикл **импорт → карточка → чтение → перелистывание → Library → карточка → продолжение** принят на этом устройстве. Actual Hermes до возврата (17:41:26 UTC) и после открытия (17:42:05 UTC) показывает для книги `c2b682ae-be5d-40b1-b6bf-aa843e0b1606` идентичные:

- progress: `0.06213638777314093`;
- CFI: `epubcfi(/6/2!/4/2[chapter-1],/8/1:74,/12/1:286)`.

Промежуточный Library (17:41:53 UTC) имеет reading context=null и карточку6%. Root лично просмотрел screenshots `/private/tmp/narra-local-5556-before-return.png`, `/private/tmp/narra-local-5556-library-return.png`, `/private/tmp/narra-local-5556-resumed.png`: тот же текст после возврата, интерфейс чтения доступен. Холодный перезапуск, все форматы/ссылки, массовый импорт и длительная стабильность этим одним циклом не подтверждены.

Провайдеры LOCAL текста/изображений/речи пока не готовы. Этот прогон не является проверкой успешной AI-генерации или озвучки. Использован Expo dev-client для переиспользования установленной сборки без native-build; тестовый маршрут строго локальный, без туннелей.
