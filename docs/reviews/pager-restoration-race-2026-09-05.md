# Восстановление вкладки: запоздалое native-событие

## Проблема и исправление

LibraryScreen уже сохраняет выбранный раздел. В actual mounted NativeSegmentedPager
воспроизведён другой дефект: после восстановления selectedIndex=1 запоздалый
onPageSelected(0) вызывает onSelect(0), позволяя родителю снова сохранить Popular.
Аналогичный сценарий воспроизведён для imperative-переключения.

Теперь компонент запоминает ожидаемую программную страницу до отправки native-команды.
Несовпадающее подтверждение не публикуется, пока не получена ожидаемая страница.
Начало реального drag снимает ожидание: пользователь может изменить выбор.
После подтверждения обычные события без drag, включая accessibility, принимаются.
Дизайн, storage и LibraryScreen не изменялись. Использован Expo building-native-ui.

## Проверки

- Агент воспроизвёл два RED до исправления; после изменения 4 mounted-теста PASS.
- Root проверил diff и независимо выполнил полный mobile: 178 файлов / 1659 PASS.
- TypeScript: `pnpm exec tsc --noEmit`, exit0.
- Native leaf замокан; это не приёмка на iOS/Android и не доказательство причины
  наблюдавшегося сброса на Android5556. Значение library_last_section не получено.

Ограничения: подтверждение native-команды ожидается без таймера; поведение при
потере acknowledgement и сложные перемежения жестов/команд ещё требуют native QA.
Этот фикс не связан доказанным образом с новым SIGSEGV Hermes.

## Дополнение после native QA на RN0.86.3

Первый guard оказался недостаточным: на5556 My books была выбрана, но физически
показывался пустой каталог. После Popular→My books карточка собственной книги
с6% вернулась, чтение/возврат работают. Это рассинхрон страницы, не потеря книги.
Native goTo игнорирует команду, если adapter ещё не содержит нужной страницы;
такой dropped-command сценарий воспроизведён в mounted-тесте. Точное время
native-событий на устройстве не записано, поэтому это модель причины, не trace.

Доработка: на несовпадающее подтверждение отправляется одна дополнительная
неанимированная команда на каждое программное переключение. Guard выставляется
до вызова, чтобы синхронные callbacks не создали рекурсию. Повторный явный выбор
ожидаемой вкладки также повторяет команду без лишнего onSelect/haptic.

Агент:3 RED→GREEN,8 mounted PASS. Root независимо проверил diff и перенёс
2 файла в изолированную RN0.86.3 установку:178 файлов /1665 PASS, TypeScriptexit0.
Проверены ограничение при10 неверных событиях, synchronous callback, drag и
accessibility после подтверждения. Результат native cold-start gate — ниже.
Если адаптер потеряет обе автоматические команды, гарантии авто-восстановления
нет; это ограничение не скрыто успешными unit-тестами.
