# Озвучка сцены: сохранность исходного текста

## Результат

До синтеза теперь проверяется весь сценарий, включая сохранённый кэш:
текст должен покрывать исходник полностью и в исходном порядке. Пробелы
могут отличаться в ответе модели, но возвращаемые сегменты берутся из
точных исходных диапазонов. Их конкатенация равна исходному отрывку.
Добавления, перестановки, дубли, потеря пунктуации и неполное покрытие
отклоняются до отправки в TTS.

Предыдущие filter/slice скрывали повреждённые сегменты и усекали ответ:
теперь malformed-элемент отвергает весь сценарий, более24 сегментов дают
явную ошибку. Исходник более12000 символов отклоняется до запроса, а не
обрезается молча; пользователь получает совет выбрать короткий отрывок
или использовать озвучку книги. Это ограничение сцены, не поддержка
бесконечно длинного сценария.

Narration всегда получает голос рассказчика и characterId=null. При
исправлении текста или голоса старый audioUri не переиспользуется.
Невалидный кэш очищается только для выбранной сцены, без удаления книги;
новый платный запрос возможен только после следующего явного нажатия.
Вместо прежней ошибки только в журнале экран показывает локализованное
сообщение ru/en и оставляет доступной кнопку повторной озвучки.

## Проверки

Агент воспроизвёл6 дефектов через настоящий generateNarraAudioScenario и
контролируемый ответ шлюза: выдуманная фраза, пропуск/перестановка,
потеря25-го сегмента, text:null, голос персонажа у narration, потеря хвоста
исходника после12000 символов. Диагностические ожидания заменены
регрессиями на отказ либо сохранность; файл больше не называется repro.

Дополнительно найдена несовместимость: bare JSON-массив считался envelope
и превращался в пустой ответ. Отдельный RED→GREEN подтвердил исправление;
поддерживаются text/content envelope, bare array и fenced JSON. Проверены
точные границы12000/12001 символов и24 сегмента.

Независимое ревью основного integrity diff:36 PASS. Финальный root mobile:
**172 suites /1584 PASS**. Core **84 suites /675 PASS**; TypeScript PASS.
Числа пересекаются и не являются метрикой качества распределения ролей.
Все ответы модели в этих регрессиях контролируемые, платных вызовов не было.

## Незакрытые границы

Это строгая защита сохранности, не доказательство правильного определения
говорящего или высокой успешности живой модели под новым prompt.
Нужен отдельный live gold-набор и native проверка ошибки/повтора/звука.
Автоматический одно-голосый fallback не добавлен: приложение не скрывает
неудавшееся распределение ролей за другим видом результата.
