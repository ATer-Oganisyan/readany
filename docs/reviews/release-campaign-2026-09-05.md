# NARRA — результаты кампании стабилизации

Дата: 5 сентября 2026. Репозиторий `mishanaer/Narra`, исходный `main`
`8d9d6bb8021990019ddd830a7b60869f8c765c66`, рабочая ветка
`codex/core-loop-audit-20260904`. Изменения локальные, без push, deployment,
публикации в App Store / Google Play. Исходная пользовательская книга сохранена.

## Решение о релизе

**Автоматический прогон и описанные локальные native-сценарии прошли;
массовый релиз не принят.**
Локальные исправления и нативные результаты ниже не подменяют успешный live
AI-сценарий: TEST API продолжает отвечать HTTP 502. Подписанный магазинный
артефакт, физические устройства и ёмкость production отдельно не проверены.

Рабочий QA-цикл: воспроизведение → исправление причины → поведенческий
RED→GREEN → настоящий iOS/Android сценарий → независимый review → общий
повтор. Проверки наличия строк в исходниках не считались доказательством
исправления поведения. Когда UI-драйвер нажал не туда или ожидал устаревший
текст, такой запуск отделён от дефекта приложения и повторён.

## Основной пользовательский сценарий

Выбран loop: библиотека → файл/ссылка → доступная для чтения книга → листание,
оглавление и настройки → персонаж/чат/профиль либо заметка → возврат к тому же
тексту → закрытие/перезапуск → повторный импорт без потери места.
Сцены и AI проверяются также в ошибке, с отменой/повтором: ожидание не должно
запирать читалку. Live success остаётся отдельным открытым условием.

| Экран / шаг | Исправлено и проверено | Граница результата |
| --- | --- | --- |
| Запуск | Согласованы установленные зависимости, native dev-client и reader assets; исправлен настоящий Metro cold-start сбой типизации | iOS build 36 и Android debug; не store archive |

| Повторный / смешанный импорт | Атомарное сохранение, проверка содержимого, отсутствие phantom-записей; новая редакция не перезаписывает старую; честные Added/updated/failed | Ошибочные файлы намеренно отклоняются; счётчик failures не является числом новых багов |
| Восстановление утраченного файла | Реальный CBZ repair на iOS/Android сохранил прежний ID/hash/страницу; на iOS исправлен не завершающийся одиночный выбор CBZ | Общий helper всех трёх picker paths; отдельные внешние providers и repair из Notes/Profile не приняты |
| URL → отмена / повтор | Реальные success, redirect, 404, повреждённый EPUB, новая редакция, зависшее тело и Cancel на обеих платформах | Localhost fixture E2E, не полный live Ficbook или каталог |
| Новая редакция → самостоятельное чтение | iOS: отдельно импортированная редакция открыта, выполнены 10 физических next и возврат в Library; старый источник сохранён | Это проверка читаемости и переходов, не 10 точных CFI-сопоставлений |
| Чтение → следующая глава | Устранены зависания ожиданий/очереди и пропуск главы через оглавление; native forward/reverse AFTER подтверждены | Собственные книги и указанные сценарии, не все возможные layout-гонки |
| Начальное открытие по адресу заметки | Готовность приходит после завершения начальной навигации, а не первого iframe load; ошибка сохраняет запрос CFI для Retry | 30 s ограничивают init и fallback вместе, не весь download/parser |
| PDF / CBZ | Физические счётчики, сохранение страницы; PDF без двойного текста и с правильным масштабом слоя выбора | Широкая матрица PDF-шрифтов и fixed-layout EPUB не пройдена |
| PDF: выделение → заметка → возврат | iOS: `diary`, SQLite `epubcfi(/6/8)`, физический переход 4→5→Notes→note→4; Android: меню действий восстановлено, собственная запись `epubcfi(/6/6)`, 3→4→note→3 | Адрес страницы, не точный диапазон слова. Разные выделения одной страницы имеют разные ключи кэша AI |
| Appearance / управление | Открытые вручную кнопки не исчезают самопроизвольно; iOS Dark/font 17 → Light/font 16 с восстановлением исходных настроек | Нет отдельной полной Dynamic Type/VoiceOver-приёмки |
| Системная тема / контраст | Убрана обратная связь принудительной темы Uniwind и RN Appearance; Dark→System возвращает светлый интерфейс без перезапуска на обеих платформах. Android labels и строка состояния используют нужный foreground | Android проверен после стабилизации кадра, latency смены темы не измерялась; полная accessibility-приёмка не заявлена |
| Персонажи → чат → профиль → книга | Локализованные Retry/ошибка, доступный профиль по имени, ввод над клавиатурой, возврат к прежнему тексту; точный контекст восстанавливается по CFI | Live AI-ответ, качество разметки и генерации не измерены при HTTP 502 |
| Сцены при недоступном AI | Poll не запускает заново terminal failure, запрос ограничен и отменяем; неактивные пустые предложения сцен не занимают страницы | Реальная успешная генерация/изображение ещё не приняты |
| Reader → Notes | Book scope, повторный Add, iOS Close/Cancel, Keep editing/Discard; две собственные записи подтверждены SQLite | Swipe-dismiss/durable draft journal не заявлены |
| Повторный возврат Notes → Reader | Возврат переиспользует точный Reader нужной книги, закрывает Notes и повторно принимает тот же CFI. По 3 native цикла на iOS и Android сохранили один Reader key; Close оставил только Tabs | Из общего блокнота нажатие открывает редактор, это не прямой переход к цитате; нестабильная доставка одного Maestro center tap отдельно отмечена в Android QA |
| Notes: вид непустого блокнота | Вкладки ниже native header, локализованный Book note, нет пустых кавычек, именованные Edit/Delete с областью 48×48 pt | Принято на iOS; локальная система компонентов/токенов сохранена |
| Сохранение заметки / смена книги | Запись подтверждается БД, поздние изменения не должны теряться; активная книга и Reader фильтруют чужие книжные аннотации | Поведенческие deferred/failure проверки; это same-user cross-book, не межаккаунтная утечка |
| Выход / завершение процесса → чтение | JSON checkpoint не откатывается от отстающей SQLite; exact text/CFI восстановлены нативно | Bounded process termination, не гарантия сохранения до фактической записи на диск |

## Что требуется до массового релиза

1. Восстановить TEST gateway и пройти живой импорт → анализ → сцена → ответ
   персонажа → возврат. Измерить успешность, p50/p95, расход и качество на
   согласованном корпусе, а не на ответах-моках.
2. Проверить подписанные release-артефакты на физических iOS/Android,
   длительный foreground/background/offline soak, доступность и обновление
   поверх прежней версии без потери библиотеки/прогресса.
3. Выполнить контролируемый rollout, восстановление резервной копии/миграций
   и нагрузочную приёмку production. Текущие локальные journals требуют
   **один gateway writer**; результаты конкурентных worker не разрешают
   произвольное горизонтальное масштабирование gateway.
4. Принять оставшиеся доступные внешние каналы: настроенный account sync,
   live catalog/Ficbook и реальные document providers. Share-in не реализован;
   зарегистрированный, но недостижимый WebDAV browser не считается готовой функцией.

Честный результат кампании — конкретные исправленные пользовательские сбои
и проверяемые доказательства. Формулировка «идеально, без багов, готово на
тысячи клиентов» до закрытия этих условий не используется.
