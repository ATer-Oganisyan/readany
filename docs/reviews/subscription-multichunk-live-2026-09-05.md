# Живой multi-chunk прогон: результат и найденный дефект

Живая серия дошла до публикации, но **не прошла приёмку полноты**: у Бориса
потерялся пример речи, хотя scanner сохранил его точную реплику и synthesis
получил её в EVIDENCE. Проверка завершилась exit1 именно на пустом speechExamples.
Это не успешный полный AI-loop и не проверка готовности к массовому релизу.

## Факты прогона

- Собственный текст, 9164 символа, три штатных чанка; SHA256
  `720f3e6342595211b560e1803c407584ac5cf92287b58c577989a3bcf90814a8`.
- Отдельная БД `narra_qa_pipeline_20260905_live_multi01`, run
  `9f03b1eb-4abf-4c74-994a-a0ef9b02f989`.
- Реальные workers, PostgreSQL, локальный HTTP generation service,
  официальный CLI с сохранённой авторизацией и моделью `gpt-5.6-luna`.
  Object storage в этом canary — memory adapter, не S3; общий cost ledger
  production gateway этим прогоном не проверялся.
- Девять отдельно просмотренных и разрешённых запросов: scan ×3, затем
  synthesis/recall/audit для Анны и Бориса. Никаких повторов/fallback/extra calls.
  Финальный campaign state: failed=false, active=false, calls=9.
- БД дошла до ready/publish: два героя, 22 observations, одна публикация.
  Полноценный повтор ensure/replay **не был выполнен в живом прогоне**:
  semantic assertion остановил canary раньше. Не переносить сюда mock-доказательства.
- Собственные edition rows удалены штатным cleanup; SELECT count(*) дал0.
  Полные private step requests/responses и pipeline-evidence сохранены.
  [Проверяемый артефакт без credentials](evidence/subscription-multichunk-live-2026-09-05.json)
  содержит ответы, публикацию, цитаты, SHA запросов и измерения.

## Качество и границы

Root и независимый агент проверили факты и источники:

- Сохранены честность Анны, терпеливость Бориса, поздняя любознательность,
  профессия Анны и родство сестра/брат. Все22 финальные цитаты совпадают с текстом.
- Scanner вернул4 наблюдения из overlap вне core первого чанка. Это нарушение
  инструкции моделью, но backend правильно отфильтровал их: дублей в публикации нет.
- Ранние personality snapshots не содержат позднюю любознательность;
  прямые evidence в snapshots нормализованы до confidence0.95.
- Описания содержат подтверждённые факты, без новых событий. Устойчивый стиль
  речи не выдуман по одной короткой реплике. Приветствия корректны, но общие —
  это не доказательство выразительного character chat.
- У Анны пример речи сохранён; у Бориса speechExamples=[], несмотря на
  «Борис ответил: «Хорошо, Анна».». Это реальная потеря полезного контекста.
- Модель выбрала неверные voice codes относительно реестра. Нормализатор
  исправил их: Che=female, She=male. Реального звука/выбора старта не проверяли.
- Описания полного профиля включают поздние факты. Правильная canonical timeline
  не доказывает отсутствие спойлеров в публичном клиентском профиле.

Машинный evaluator отдельно требует ручного review смыслов дополнительных фактов,
био и creative-полей. После завершения серии исправлена его собственная погрешность:
конечная точка и внешние пробелы у заранее разрешённых формулировок родства больше
не вызывают ложного отказа. Другие отношения, отрицание и дополнительные утверждения
не разрешены. Пропуск реплики этим не замаскирован; исходный артефакт неизменён.

## Исправление и дальнейшая приёмка

В normalizer добавлено восстановление только при отсутствии пригодных модельных
примеров: до трёх целых собственных character_dialogue цитат, по порядку текста,
с проверками ID, типа, диапазона, длины и confidence. Дубли удаляются; длинные
цитаты пропускаются, не обрезаются; speechStyle не генерируется.
Принятые модельные примеры и provider claim accounting сохраняются.

Записанные неизменённые ответы повторно прошли настоящую цепочку workers/БД:
два отдельных прогона (`narra_qa_pipeline_20260905_replay01` и `..._replay02`).
Оба восстановили реплику Бориса; 10 jobs, 22 observations, одна публикация,
девять записанных ответов, повторный ensure/worker replay idle. Новых вызовов
модели не было. Replay-helper намеренно оставляет исходное speechExamples=[];
исправление выполняет production normalizer, а не тестовая подмена ответа.

Финальный локальный CI-набор: **47 PASS / 0 SKIP**, включая три свежие БД,
записанный replay и mixed HTTP smoke. Связанные backend/contracts/service tests:
**82 PASS / 0 SKIP**. `actionlint` и `git diff --check` PASS.
Полный локальный backend без внешних сервисов:828 PASS,21 SKIP,0FAIL;
эти21 пропуска требуют отдельного PG/S3 CI-прогона и не засчитываются.
Первоначальный живой FAIL сохраняется в отчёте; offline replay не называется
новым успешным live-прогоном. Полный ручной quality gate продукта остаётся открытым.

Новые результаты используют `book-analysis-v52` / `character-profile-v15`.
[Условия выкладки](speech-fallback-rollout-2026-09-05.md): завершить старые jobs
совместимыми workers, согласовать rollout; повторный импорт может вызвать новый
анализ. Сохранённые профили не переписаны, деплоя и массовой перегенерации не было.

Параллельная iOS-проверка нашла [недоступный Cancel внутри оглавления](ios-import-toc-2026-09-05.md).
Этот дефект ещё не исправлен. Сцены, диалоги, реальная озвучка, физические устройства
и смешанная длительная нагрузка остаются релизными барьерами.
