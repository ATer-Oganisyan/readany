# Синтез персонажа после потери задания

Подтверждённая гонка: пока getSynthesizeInput ожидал БД, heartbeat получал
LEASE_LOST, но старый worker всё равно запускал генератор. Публикация уже
защищена токеном lease; проблема — лишняя дорогая работа и задержки.

Теперь подтверждённая потеря lease отменяет запрос через pipeline и HTTP client.
Перед генерацией и после её завершения проверяется отмена. Поздний ответ не
публикуется; старый обработчик не пытается перевести чужое задание в failed.
AbortError при чтении тела нормализуется в исходную причину LEASE_LOST.
Временная ошибка БД не считается потерей lease. Heartbeat не запускает
перекрывающиеся продления и очищается после завершения.

Приёмка: исходный worker regression RED→GREEN; два transport regression
RED→GREEN. Итого **36 targeted PASS**, включая5 worker-race tests и4 transport
tests, два из них используют настоящий loopback HTTP (ожидание ответа и
частично полученное тело). Независимый агент воспроизвёл ошибку, обнаружил
дополнительную ветку AbortError и принял исправленный scoped diff.
Expo Networking использован для проверки явной отмены и обработки ошибок.
