# Живой production-пайплайн на коротком собственном тексте

На коде `4e43737` выполнен `book-analysis-pipeline-canary.mjs --stage-live`:
настоящие workers → PostgreSQL → внутренний HTTP generation service →
официальный CLI `gpt-5.6-luna` через сохранённый вход. Каждый из четырёх
точных запросов просмотрен перед отдельным разрешением SHA. Повторов и fallback нет.

Результат: exit0, 7 jobs, 4 observations, один персонаж, одна публикация,
traits=[«честность»]. Повтор ensure и workers — тот же run и idle без новых
вызовов модели. После штатного cleanup SELECT count(*) FROM book_editions дал0.
Отдельная тестовая БД со схемой сохранена, пользовательские данные не менялись.

[Артефакт с четырьмя фактическими ответами](evidence/subscription-window-live-recheck-2026-09-05.json)
позволяет проверить шаги. Scanner отделил устойчивую честность от одиночного
закрытия окна. Synthesis сохранил честность; recall не добавил недоказанных
качеств; audit подтвердил исходную цитату и описание. Пол/внешность/стиль речи
не проверялись как отдельные критерии этого canary; голос модель выбрала She
при female — соответствие финального голоса требует проверки normalizer/клиента.

Это один короткий текст, один чанк, memory object storage вместо S3.
Полный опубликованный профиль window-harness отдельно не сохраняет; артефакт
содержит raw model responses и фактический итог прогона, не дамп публикации.
Нет приёмки выразительности диалога, изображений, аудио, полноразмерных книг,
нативного UI или нагрузочной ёмкости. Суммарное время включает ручные разрешения
и не используется как пользовательский SLA.
