## Что изменилось

- Каталожные книги появляются с целевой обложкой после её загрузки, без подмены цветной заглушкой. При ошибке загрузку можно повторить
- Исправлено обрезание теней в каруселях поиска
- Книги в каруселях поиска уменьшены на 20%; отступы между ними сохранены
- По стрелке рядом с категорией открывается полный список книг: крупный заголовок и сетка в две колонки
- Для стрелки используется `chevron-small-right` из Mishanaer Icons, цвет — `Primary 40`

## Что проверить на телефоне

1. Открыть поиск и пролистать карусели: проверить обложки, тени и отступы
2. Открыть категорию по стрелке, прокрутить список и вернуться назад
3. Открыть книгу из категории
4. Повторить проверку после перезапуска приложения и при медленном интернете
