# Narra 1.3.5 (67) — TestFlight

Статус: подготовка локальной сборки 27 августа 2026 года

Предыдущая опубликованная версия: 1.3.5 (66), группа Narra External

## Что изменилось

- Исправлено восстановление читалки при сбое локального сервера книг. Перед открытием проверяется его доступность; при необходимости сервер запускается заново
- Кнопка «Повторить» заново открывает читалку с сохраненной позицией
- Добавлено восстановление после завершения процесса читалки системой
- Внизу профиля появилась кнопка «Поделиться логами». Она открывает системное меню отправки файла диагностики; логи сохраняются после перезапуска приложения
- В диагностический файл не включаются тексты книг, переписки и ключи
- Исправлены подписи профиля на английском языке; для логов используется иконка файла из Mishanaer Icons

## Что проверить на телефоне

1. Открыть несколько книг и полистать страницы
2. Свернуть приложение, заблокировать телефон, затем вернуться к чтению
3. Если загрузка завершилась ошибкой, нажать «Повторить» и проверить сохраненную позицию
4. Открыть Профиль → Поделиться логами и отправить файл Narra-logs.json
5. Проверить профиль на русском и английском языках
