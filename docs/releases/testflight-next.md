## Препятствия при отправке

- Облачная сборка не запустилась: закончился месячный лимит iOS-сборок Free plan. По ответу EAS лимит обновится 1 сентября 2026 года. Использована локальная сборка; платный тариф не подключался
- Счетчик EAS отстал от ручных загрузок: в нем был `61`, хотя в Apple уже были билды до `64`. Счетчик синхронизирован; итоговый релиз получил номер `66`
- Параметр EAS Submit `--what-to-test` доступен только Enterprise-аккаунтам. Отправка выполняется без него; заметки добавляются через App Store Connect
- Первую локальную сборку 65 Apple отклонила: `Unsupported SDK or Xcode version` (409), [отправка `5d65c26b`](https://expo.dev/accounts/mishanaer/projects/readany/submissions/5d65c26b-25d4-4c57-842d-b976410e5bc0). Причина: команда из `~/.local/bin/xcodebuild` подхватывала Xcode 27 beta 1 вместо выбранного в системе Xcode 26.6. Билд 66 пересобран с Xcode `26.6 (17F113)`, правильный SDK подтвержден в готовом IPA
