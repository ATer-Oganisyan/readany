## Что препятствует отправке

1. EAS production передает `EXPO_PUBLIC_OPENROUTER_API_KEY`. Модуль `src/config/bundled-ai.ts` читает его напрямую: при сборке ключ встраивается в приложение. Некоторые ИИ-функции используют этот ключ, поэтому его простое отключение изменит функциональность. До отправки требуется решение владельца о переносе запросов на сервер либо явное принятие риска распространения ключа
2. App Store Connect требует входа пользователя. Без него не проверены последний опубликованный билд и состояние внешней группы `Narra External`
3. Production-профиль использует `https://api-test.narra.disrupt.builders`; адрес сохранен без изменений. Перед выпуском подтвердить, что это нужный сервер для тестировщиков

Expo предупреждает, что значения `EXPO_PUBLIC_*` доступны в собранном приложении: [документация переменных окружения](https://docs.expo.dev/guides/environment-variables/#security-considerations)
