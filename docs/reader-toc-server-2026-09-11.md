# Серверное оглавление EPUB — 11 сентября 2026

В каталожном «Идиоте» `nav.xhtml` содержит «Заглавие» и «Текст», а `toc.ncx` — заглавие и 50 глав. И сервер, и читалка раньше безусловно предпочитали NAV. Приложение не обращалось к `/v2/books/:id/content/toc`.

## Изменение

- Сервер сравнивает действительные адреса в NAV и NCX. Более полный NCX выбирается, если сохраняет все действительные адреса NAV; дубликаты и отсутствующие якоря не увеличивают полноту. При равенстве сохраняются NAV и его вложенность.
- В ответ добавлены `reader_href` (адрес от корня EPUB, с декодированными именами и якорями, совместимый с движком) и `source_content_hash` (хеш исходного файла, отдельно от хеша нормализованного текста). Старое поле `href` сохраняет прежнюю семантику.
- Приложение запрашивает оглавление для каталожных EPUB, проверяет соответствие файлу, передаёт готовый список движку и сохраняет ответ для офлайн-чтения. Открытие книги не ждёт сеть. Локальные книги, остальные форматы и случай недоступного API сохраняют прежнее поведение.
- Движок обновляет список и определение текущей главы без перезагрузки книги и смены позиции. Выделение в панели опирается на адрес главы, поэтому одинаковые названия не выделяются одновременно.

## Проверка

- На реальном скачанном EPUB «Идиота»: 51 пункт, 51 сегмент; 1 312 604 символа текста. Исходный файл не меняется.
- В собранной `reader.html` в браузере: исходные 2 пункта заменились 51 серверным; переходы к главам 1, 22 и 50 прошли; текущая глава обновляется, необработанных ошибок JavaScript нет.
- Повторная проверка после ревью: при одновременном применении длинного старого и короткого нового оглавления сохраняется новый список. Добавлена защита от завершения старой асинхронной операции после новой.
- Пройдено 114 серверных и 30 клиентских тестов.
- Проверены NAV/NCX, вложенность, битые ссылки, дубликаты, неизменность текста и исходных секций; сериализация API и соответствие версии файла; офлайн-кеш, поздние ответы и смена книги, выбор главы с повторяющимся названием.
- TypeScript и сборка reader assets проходят. На iOS Simulator с продовым API скачано издание `d50cc204-c233-4d3a-a9d6-1941d99e8af4`: получены и сохранены в кеш 52 пункта с совпадающим хешем EPUB. Нативный список показывает главы; нажатие «Глава III» открывает её и меняет текущую главу (страница 57 из 1627).

## Применение на сервере

**Применено на проде 11 сентября 2026.** Gateway и шесть `book-analysis-worker` обновлены штатным `deploy.sh`; все healthy. Образ `narra-gateway:0.0.2026091101` построен поверх действовавшего `0e63014e09edb4423c8aa15fbede52fe32f67d7a` и содержит только пять изменённых серверных файлов оглавления. Остальные незавершённые локальные изменения в образ не включены. Образ сохранён в `compose.env` и `deployment.env`.

По запросу пользователя проверка выполнена на продовом окружении. Metro перезапущен через `READANY_NARRA_BACKEND=production ./script/build_and_run.sh`, без нативной пересборки. Старое тестовое издание отсутствует в рабочей базе и сохранено локально; для проверки скачано актуальное продовое издание из каталога.

Предварительный проход проверил 391 книгу без записи. Перед применением сохранены предыдущие данные в `/opt/narra-production-v2/backups/toc-before-20260911.json`; обновлены 391 из 391 оглавлений, текст и его хеши совпали. Повторный проход: `candidates: 0`, `updatedBooks: 0`. Продовый `/health`: `ok: true`. Для отката кода сохранён предыдущий образ и файлы `compose.env.before-toc-20260911`, `deployment.env.before-toc-20260911`.

Команды для повторения процедуры в окружении сервиса с настроенными PostgreSQL и object storage:

```sh
BOOK_CONTENT_NAVIGATION_BACKFILL_REFRESH=1 BOOK_CONTENT_NAVIGATION_BACKFILL_DRY_RUN=1 node books/backfill-book-content-navigation.mjs
```

Предварительный режим ничего не записывает и не запускает миграции. Для каждой книги проверяются длина и SHA-256 нормализованного текста, выводятся число пунктов до/после и выбранный источник. Несовпадение текста останавливает операцию.

Затем применить проверенное обновление:

```sh
BOOK_CONTENT_NAVIGATION_BACKFILL_REFRESH=1 node books/backfill-book-content-navigation.mjs
```

Скрипт выбирает ту же подготовленную версию, что API, и меняет только `content_navigation` и `updated_at` при отсутствии конкурентных изменений. Версия выбора 2 исключает повторную обработку. Лимит прохода — 1000 книг (`BOOK_CONTENT_NAVIGATION_BACKFILL_LIMIT`); повторять до `candidates: 0`. Исходные EPUB, текст, прогресс читателя и опубликованные результаты анализа не перезаписываются. Переимпорт книги на телефоне не нужен: после обновления сервера достаточно переоткрыть её с интернетом.

Изменение границ `content_navigation` влияет на последующую подготовку озвучивания, использующую эти границы. Существующие публикации озвучивания не пересоздаются этим скриптом; их сквозная совместимость с обновлёнными границами на удалённом окружении не проверена.
