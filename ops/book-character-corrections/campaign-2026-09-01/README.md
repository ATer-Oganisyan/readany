# Кампания исправления 12 книг — 2026-09-01

## Ограничения

- Ни один исходный персонаж, publication, markup version, artifact или evidence не удаляется из БД.
- Analysis pipeline и LLM не запускаются.
- Изменения выполняются только через `book-character-correction-v1` поверх точной опубликованной базы.
- Каждая книга проходит `preview`, затем отдельные `stage` и `enable`, после чего проверяется reader projection.
- При ошибке включённый документ отключается по его точному `documentHash`; исходная публикация остаётся источником rollback.

## Выявленный риск overlay

Первый server preview «Вишнёвого сада» был отклонён до записи: после redirect объединённый `identityEvidenceIds` превысил контрактный максимум 64. Для overlay подготовлено детерминированное ограничение: при переполнении сохраняются до 48 ID канонического профиля и до 16 ID redirect-профилей, распределённых round-robin между несколькими дублями. Role, Bio и Personality сохраняют собственные evidence-ссылки; исходные evidence в БД не меняются.

## Журнал применения

Заполняется только фактическими результатами server preview, `documentHash`, stage, enable, post-check и rollback-состоянием. Сомнительные или отклонённые документы остаются в репозитории, но не включаются.
