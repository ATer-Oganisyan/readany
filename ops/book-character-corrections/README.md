# Per-book character corrections

Сюда добавляются только проверенные JSON-файлы вида:

```text
<bookEditionId>.json
```

Файл должен соответствовать `book-character-correction-v1` и точной текущей базе книги. Наличие файла в репозитории ничего не применяет автоматически.

Порядок работы и команды описаны в [`docs/book-character-correction-overlay.md`](../../docs/book-character-correction-overlay.md).

Правила:

- один файл — одна книга;
- не хранить пароли, токены и полные тексты книг;
- не создавать новые `characterKey`;
- сначала `preview`, затем `stage`;
- `enable` выполняется отдельно только после явного подтверждения конкретного `documentHash`;
- после новой публикации книги старый файл не обновлять механически: повторно проверить evidence и сформировать новую точную base binding.
