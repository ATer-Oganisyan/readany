# Play / Loader / Pause

Editable SVG prototype and the approved animation archives. The same two filled contours morph throughout; each has eight cubic Bézier anchors. There are no opacity crossfades or icon swaps.

## Approved motion

- Direct play ↔ pause and loading entry: 300 ms, with a −8° anticipation before entering the loader.
- Loader: two opposing 93.5° arcs, one turn in 400 ms.
- Loader → pause: 350 ms spring, frequency 17 rad/s and damping ratio 0.465. Exit starts at −90° (equivalent phases .25/.75); contours reach their final shape before the first upright crossing, followed by rotational overshoot.
- Pause legs: 94.5% of their original width, with outer edges preserved.

The native app uses the optimized `packages/app-expo/assets/icons/anim_play_loader_pause.json`, generated by `export-native.mjs`. Its separate pause → loader clip has the same anticipation and timing as play → loader. Audio-state behavior, minimum loop, buffering delay and cancellation are documented in `packages/app-expo/src/lib/tts-motion/README.md`.

## Preview

From the repository root:

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory tools/lottie-preview
```

Open http://127.0.0.1:4178/. `index.html` provides playback and inspection controls; `exits.html` compares six exit angles; `reference-original.html` shows the original Lottie. These are design tools, not the app's audio-state controller.

## Sources and export

- `saved/approved/` — preserved SVG/Lottie snapshots and motion metadata.
- `build-svg.mjs` and `loader-geometry.mjs` — SVG authoring and geometry.
- `export-lottie.mjs` — SVG-to-Lottie export.
- `export-native.mjs` — optimized native composition; validates reconstructed geometry against the approved archive before writing.
- `animation.json` — relative symlink to the original play/pause app asset.
- `vendor/` — local Lottie renderer and its license.

```sh
node tools/lottie-preview/build-svg.mjs
node tools/lottie-preview/export-native.mjs
```

The first command rebuilds the editable SVG previews. The second reads the approved archive and rebuilds the native JSON (about 244 KiB); editing the preview alone does not replace the approved archive. See the native motion README for validation results and device-testing limitations.
