# Narra Face Lab

Локальная браузерная лаборатория для настройки выражений и анимаций точного SVG-фейса Narra.

Лаба использует один исходник [`packages/app-expo/assets/narra-face.svg`](../../packages/app-expo/assets/narra-face.svg) и сохраняет четыре его слоя — нос, левый глаз, правый глаз и бровь. Встроенные пресеты управляют этими слоями без подмены логотипа процедурным персонажем.

## Что внутри

- 27 готовых expression-пресетов;
- 23 готовые анимации с таймлайнами, переходами, паузами и морганием;
- ручная настройка поворота фейса, формы, положения и наклона глаз;
- создание, дублирование и редактирование собственных выражений и анимаций;
- Photo Mode с экспортом текущего кадра в SVG или PNG;
- экспорт и импорт всего проекта в JSON;
- автоматическое сохранение проекта в локальном хранилище браузера.

Runtime-экспорт в старые пакеты `@bible-strong/avatar-*` для Narra Face скрыт: эти пакеты знают только процедурную геометрию оригинальной лабы и не могут воспроизвести наш SVG без подмены внешности. Для переноса пресетов и анимаций используй экспорт проекта JSON.

## Запуск из корня Narra2

Требуются Node.js 22.12+ и pnpm.

```bash
pnpm avatar:lab
```

По умолчанию Vite откроет лабораторию на [http://localhost:5173](http://localhost:5173).

Production-сборка:

```bash
pnpm avatar:lab:build
```

## Запуск из этой папки

```bash
pnpm install
pnpm dev
```

Полная проверка:

```bash
pnpm check
```

## Где что лежит

- `src/assets/narra-face.svg` — SVG, который используется рендерером;
- `src/features/rendering/narraFaceGeometry.ts` — трансформации слоёв фейса;
- `src/features/studio/defaultStudioDocument.json` — встроенные выражения и анимации;
- `src/features/export/snapshotExporter.ts` — экспорт текущего кадра;
- `public/narra-face.svg` — публичная копия для интерфейса.
