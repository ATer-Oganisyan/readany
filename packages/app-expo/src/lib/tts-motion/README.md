# Playback button

The iOS audiobook sheet uses one Lottie composition with separate clips for direct play/pause and loading. Keeping one view avoids asset replacement and opacity crossfades. Its eight-anchor contours come from `tools/lottie-preview/saved/approved/`; regenerate the native JSON with `node tools/lottie-preview/export-native.mjs` from the repository root. The SVG snapshot remains the editable reference.

`sampleMotion` runs on the Reanimated UI runtime and owns presentation only, never audio commands. The memoized Lottie view receives native animated progress, avoiding JS requestAnimationFrame, React renders and JSON serialization per frame. `PlaybackMotion` is a test adapter for that same sampler. Direct transitions and play-to-loader take 300 ms; loader-to-pause is the approved 350 ms spring. Pause-to-loader has its own 300 ms clip (6–6.3 s), with the same −8° anticipation, clockwise acceleration and morphology timing as play entry. It joins the spin at phase .25 with matching speed; eight anchors per contour are retained. The loader turns in 400 ms. Successful exit requires at least one complete turn after entry, then the nearest equivalent phase .25/.75. Cancellation exits toward play at phase 0. Loading from play has an 80 ms grace period. Reduced motion uses static poses.

`useTTSNativePlayer` keeps the current icon while scrubbing, reports loading after release for pending seeks, and shows native buffering only after 500 ms continuously. Short buffering events reset the timer. Chapter seeks preserve paused intent. Reader seek callbacks receive a generation guard so canceled or superseded async work cannot restart playback.

Validation: controller/seek/store/asset tests and TypeScript. The actual component was tested in an isolated iOS screen with a forced 1200 ms JavaScript stall. Recording shows continuous loader rotation (no frame interval above 20 ms in the sampled loops) and visible intermediate morph poses. The temporary diagnostic screen was removed. Full audiobook-network behavior still needs observation in the normal player; the diagnostic test isolates animation performance from reader/network behavior.

Production export optimization: the connected JSON is about 244 KiB (previously 995 KiB). Layer rotation is separated from residual eight-anchor path morphs; the spinner needs only two rotation keys per contour. Coordinates are rounded to three decimals, redundant shape `e` values are omitted (the following `s` is the endpoint), and adaptive simplification retains clip boundaries. The exporter validates reconstructed vertices and handles against the approved source at 2400 Hz before writing; maximum deviation is below 0.11 on the 320-unit canvas. A Lottie-web SVG renderer comparison covered 620 sampled frames across all clips against the previous native JSON, with maximum sampled outline deviation 0.149 units. The revised JSON passes motion/asset tests and TypeScript; this export still needs a fresh native-device visual/performance check. Approved SVG/JSON source archives remain unchanged.
