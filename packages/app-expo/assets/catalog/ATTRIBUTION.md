# Bundled Narra catalog

The EPUB files in this directory were supplied for the Narra catalog.

Sixteen files contain their Wikisource source URL and the original Creative Commons BY-SA 3.0 / GNU Free Documentation License metadata inside the EPUB package. The embedded FreeSerif font files were removed to avoid shipping the same fonts with every book; book text, chapters, images, metadata, source links, and license declarations were preserved.

`eugene-onegin.epub` contains only Calibre title and author metadata in the supplied file. Its text is a public-domain work by Alexander Pushkin; the source edition was not identified in the archive.
