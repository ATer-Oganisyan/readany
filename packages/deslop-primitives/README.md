# @deslop/primitives

Локальный workspace-пакет с примитивами из
[`mishanaer/deslop`](https://github.com/mishanaer/deslop/tree/main/primitives).

Он хранится в монорепозитории, чтобы локальные и EAS-сборки использовали одну
зафиксированную версию токенов, интерфейсного шрифта SB Sans Interface,
книжных шрифтов SB Serif Text и SB Serif Condensed, а также Material Symbols Rounded.
Обновления из исходного репозитория переносятся осознанно отдельным изменением.
